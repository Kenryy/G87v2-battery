# MCHOSE G87 V2 电量托盘监控

一个极简的 Windows 托盘小工具，在任务栏图标上直接显示迈从（MCHOSE）G87 V2 无线键盘的剩余电量。

官方驱动需要打开网页、连接设备才能看电量。这个程序直接通过 HID 向 2.4G 接收器查询，读数只要几百毫秒，常驻后台几乎不占资源。

## 功能

- **图标即电量**：托盘图标直接渲染百分比数字，不用点开任何窗口
- **三段配色**：正常（随任务栏深浅自动切黑/白）、偏低（琥珀色）、低电量（红色）
- **自动刷新**：1 / 5 / 10 / 15 / 30 / 60 分钟可选，也可关闭
- **低电量提醒**：阈值 10% / 20% / 30% 可调，触发时弹系统通知
- **开机自启**：写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，不申请管理员权限
- **单文件绿色版**：打包后是一个 exe，无安装程序、无注册表残留（除自选项）

## 系统要求

- Windows 10 / 11
- 迈从 G87 V2 键盘，且通过 **2.4G 接收器**连接（蓝牙模式不支持，官方驱动同样不支持）
- 源码运行需要 Python 3.9+；直接用 exe 则无需 Python

## 使用说明

| 操作 | 效果 |
| --- | --- |
| 鼠标悬停 | 显示电量与最后更新时间 |
| 左键单击 / 双击 | 立即刷新一次 |
| 右键 → 立即刷新 | 立即刷新一次 |
| 右键 → 自动刷新间隔 | 选择 1–60 分钟，或关闭自动刷新 |
| 右键 → 低电量提醒 | 选择触发阈值 10% / 20% / 30% |
| 右键 → 开机自启 | 勾选后写入注册表 Run 项 |
| 右键 → 退出 | 结束程序 |

配置保存在 `%APPDATA%\MchoseBattery\config.json`，删除该目录即恢复默认：

```json
{
  "interval_min": 10,
  "autostart": false,
  "low_threshold": 20
}
```

`interval_min` 为 `0` 表示不自动刷新。



## 已知限制

- 只适配 G87 V2（VID/PID 硬编码）。其他型号协议不同，需要自己改常量并重新抓包。
- 官方客户端或网页驱动正在占用设备时，可能读到 `None`；关掉它们再试。
- 接收器被系统休眠策略挂起后，首次刷新可能失败一次，下次刷新会恢复。
- 只在 Windows 上实现：用到了 `winreg` 读注册表判断任务栏明暗、写开机自启。
